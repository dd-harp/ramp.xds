# Compute blood-feeding terms dynamically

Update time-at-risk matrices and compute local and total blood host
availability.

## Usage

``` r
blood_feeding_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
