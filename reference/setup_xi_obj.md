# Set up bionomic port for delayed maturation parameter (**L**)

Set up a [bionomic
port](https://dd-harp.github.io/ramp.xds/reference/xds_info_port.md) to
compute the baseline delayed maturation parameter in response to mean
crowding, \\xi\\, for a static model.

## Usage

``` r
setup_xi_obj(xi, L_obj)
```

## Arguments

- xi:

  the delayed maturation parameter in response to mean crowding

- L_obj:

  an **`L`** module object

## Value

an **`L`** module object
