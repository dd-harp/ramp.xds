# Update blood trap availability

Dispatch updates for blood trap availability. Dispatches on
`class(xds_obj$patches$blood_traps_obj[[s]])`.

## Usage

``` r
update_blood_traps(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
