# Make type2 egg laying rates

Set up a type2 vector

## Usage

``` r
make_F_nu_type2(nPatches, options = list(), vx = 0.3, sv = 0.1)
```

## Arguments

- nPatches:

  is the number of patches

- options:

  is a set of options that overwrites the defaults

- vx:

  the maximum laying

- sv:

  the shape parameter

## Value

an object to set up egg laying
