# Get habitat matrix, \\N\\

Inspect the habitat membership matrix.

## Usage

``` r
get_habitat_matrix(xds_obj)
```

## Arguments

- xds_obj:

  an **`xds`** model object

## Value

a [matrix](https://rdrr.io/r/base/matrix.html)
