# Get mean forcing

Get mean egg deposition rates for a trivial **MY** model.

## Usage

``` r
# S3 method for class 'eggs'
get_mean_forcing(xds_obj, ix = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

a [vector](https://rdrr.io/r/base/vector.html) of mean egg deposition
rates for the indexed vector species
