# Update other blood hosts

Port function for the other_blood_hosts, \\\Theta\\. Dispatches on
`class(xds_obj$XY_interface$other_blood_hosts_obj[[s]])`.

## Usage

``` r
update_other_blood_hosts(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
