# Check emigration-loss fraction

Check that the emigration-loss fractions are between zero and one and
have length `nPatches`.

## Usage

``` r
check_mu(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the validated emigration-loss fraction
