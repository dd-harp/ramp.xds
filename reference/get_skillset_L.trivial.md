# The **L** module skill set

The **L** skill set is a list of a module's capabilities

## Usage

``` r
# S3 method for class 'trivial'
get_skillset_L(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- s:

  the species index

## Value

the **L** module skill set, as a list
