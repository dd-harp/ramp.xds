# Mosquito bionomics for `trivialMY` (**MY**)

Implements
[MBionomics](https://dd-harp.github.io/ramp.xds/reference/MBionomics.md)
for the `trivialMY` module.

## Usage

``` r
# S3 method for class 'trivialMY'
MBionomics(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
