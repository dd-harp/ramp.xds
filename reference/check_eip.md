# Check the extrinsic incubation period

Check that EIP values are numeric, non-negative, and have length
`nPatches`.

## Usage

``` r
check_eip(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the validated extrinsic incubation period in days
