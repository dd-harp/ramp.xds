# Get parameters for `trivialXH` (**XH**)

Return stored parameter values for the `trivialXH` module.

## Usage

``` r
# S3 method for class 'trivialXH'
get_XH_pars(xds_obj, i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

a [list](https://rdrr.io/r/base/list.html)
