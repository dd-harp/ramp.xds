# Set up no travel

Set time away to zero for each stratum of the selected host species
using
[change_time_away](https://dd-harp.github.io/ramp.xds/reference/change_time_away.md).

## Usage

``` r
# S3 method for class 'no_travel'
setup_time_away(name, xds_obj, options = list(), i = 1)
```

## Arguments

- name:

  a setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- i:

  the host species index

## Value

an **`xds`** model object
