# Setup demographic matrix

Setup the demographic matirx

## Usage

``` r
# Default S3 method
setup_mortality_matrix(name, xds_obj, options, i = 1)
```

## Arguments

- name:

  a setup method

- xds_obj:

  an **`xds`** model object

- options:

  options list (overrides command line arguments)

- i:

  the species index

## Value

an **`xds`** object
