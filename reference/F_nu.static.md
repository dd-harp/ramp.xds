# Static model oviposition rate (**MY**)

Return the baseline oviposition rate for a static model.

## Usage

``` r
# S3 method for class 'static'
F_nu(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\nu\\, the baseline oviposition rate
