# Change the blood_traps

Set blood trap availability for vector species `s`.

## Usage

``` r
change_blood_traps(blood_traps, xds_obj, s = 1)
```

## Arguments

- blood_traps:

  a numeric vector of patch-level availability

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
