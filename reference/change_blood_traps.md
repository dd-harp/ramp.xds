# Change the blood_traps

Update the blood_traps for the \\s^{th}\\ vector species, and trigger
updates for the `XY` interface.

## Usage

``` r
change_blood_traps(blood_traps, xds_obj, s = 1)
```

## Arguments

- blood_traps:

  a blood_traps

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
