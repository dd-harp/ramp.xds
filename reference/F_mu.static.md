# Static model emigration-loss fraction (**MY**)

Return the baseline emigration-loss fraction for a static model.

## Usage

``` r
# S3 method for class 'static'
F_mu(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\mu\\, the baseline emigration-loss fraction
