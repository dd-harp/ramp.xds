# Change F_shock

Change the shock function when `forced_by = "eir"`

## Usage

``` r
# S3 method for class 'eir'
change_F_shock(F, xds_obj, s = 1)
```

## Arguments

- F:

  new shock function

- xds_obj:

  an **`xds`** model object

- s:

  the vector species indeF

## Value

an **`xds`** object
