# Change parameters for `trivial` (**L**)

Change `Lambda`, `F_season`, `F_trend`, or `F_shock`

## Usage

``` r
# S3 method for class 'trivial'
change_L_pars(xds_obj, s = 1, options = list())
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

- options:

  a named list

## Value

an **`xds`** object

## Note

Utilities for trace functions are in `ramp.trace`
