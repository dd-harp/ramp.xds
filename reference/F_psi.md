# Compute the baseline maturation rate (**L**)

Compute the baseline maturation rate.

## Usage

``` r
F_psi(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nHabitats`
