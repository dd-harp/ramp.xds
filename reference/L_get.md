# Get functions (**L**)

A list of get functions for aquatic mosquito modules.

- [`get_L_vars`](https://dd-harp.github.io/ramp.xds/reference/get_L_vars.md)
  – get state variables from \\y\\

- [`get_L_ix`](https://dd-harp.github.io/ramp.xds/reference/get_L_ix.md)
  – get variable indices

- [`get_L_inits`](https://dd-harp.github.io/ramp.xds/reference/get_L_inits.md)
  – get initial values

- [`get_L_pars`](https://dd-harp.github.io/ramp.xds/reference/get_L_pars.md)
  – get parameters

- [`get_L_orbits`](https://dd-harp.github.io/ramp.xds/reference/get_L_orbits.md)
  – get saved orbits

- [`get_psi`](https://dd-harp.github.io/ramp.xds/reference/get_psi.md) –
  get the maturation rate

- [`get_phi`](https://dd-harp.github.io/ramp.xds/reference/get_phi.md) –
  get the density-independent mortality rate

- [`get_xi`](https://dd-harp.github.io/ramp.xds/reference/get_xi.md) –
  get the delayed maturation parameter

- [`get_theta`](https://dd-harp.github.io/ramp.xds/reference/get_theta.md)
  – get the slope of density-dependent mortality
