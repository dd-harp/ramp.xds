# make a Kernel-Based Mosquito Dispersal Matrix

make a Kernel-Based Mosquito Dispersal Matrix

## Usage

``` r
make_K_matrix_xy(xy, F_K = F_exp, V = list())
```

## Arguments

- xy:

  is a vector of the xy-coordinates of patch locations

- F_K:

  is a function that weights putative locations by distance

- V:

  variables
