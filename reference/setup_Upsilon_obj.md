# Set up the Upsilon object

Set to `dde` if **MY** is a delay differential equation

## Usage

``` r
setup_Upsilon_obj(xds_obj, s = 1, dede = FALSE)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

- dede:

  is it a delay differential equation that needs \\\Upsilon\\

## Value

an **xds** model object
