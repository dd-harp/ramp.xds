# Check ovitraps

Check that

- all elements are non-negative

- length(ovitraps) == nPatches

## Usage

``` r
check_ovitraps(ovitraps, nP)
```

## Arguments

- ovitraps:

  ovitrap availability

- nP:

  the number of patches
