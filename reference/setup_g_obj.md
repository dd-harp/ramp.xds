# Set up bionomic port for mosquito mortality rate (**MY**)

Set up a [bionomic
port](https://dd-harp.github.io/ramp.xds/reference/xds_info_port.md) to
compute the baseline mosquito mortality rate, \\g\\, for a static model.

## Usage

``` r
setup_g_obj(g, MY_obj)
```

## Arguments

- g:

  the mosquito mortality rate

- MY_obj:

  an **`MY`** module object

## Value

an **`MY`** module object
