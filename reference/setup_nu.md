# Setup nu

Set up the egg laying rate (\\\nu\\) for static systems

## Usage

``` r
setup_nu(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a or setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** object
