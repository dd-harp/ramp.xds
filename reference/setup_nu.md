# Set up oviposition rates (**MY**)

Set up the oviposition rate (\\\nu\\) for static systems

## Usage

``` r
setup_nu(name, xds_obj, options = list(), s = 1)

setup_egg_batch_rates(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an oviposition rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
