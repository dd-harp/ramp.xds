# Set up static mosquito mortality rate

Set up supplied static mosquito mortality rates.

## Usage

``` r
# S3 method for class 'as_is'
setup_F_g(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a or setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
