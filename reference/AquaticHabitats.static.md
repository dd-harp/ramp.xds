# Aquatic Habitat Dynamics

Computes eggs laid leaving the habitat interface unmodified.

## Usage

``` r
# S3 method for class 'static'
AquaticHabitats(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
