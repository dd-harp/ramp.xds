# Update the blood search weights

Dispatch the update for blood search weights of host species `i`.

## Usage

``` r
update_blood_search_weights(t, y, xds_obj, i)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

an **`xds`** model object
