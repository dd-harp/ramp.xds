# Static model patch emigration rate (**MY**)

Return the baseline patch emigration rate for a static model.

## Usage

``` r
# S3 method for class 'static'
F_sigma(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\sigma\\, the baseline patch emigration rate
