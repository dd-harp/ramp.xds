# Update the initial values

Update the initial values

## Usage

``` r
update_inits(xds_obj, y0 = NULL)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- y0:

  a [vector](https://rdrr.io/r/base/vector.html) of initial values; if
  `NULL`, use the last simulation state

## Value

an **`xds`** model object
