# The **XH** module skill set

The **XH** skill set is a list of a module's capabilities.

## Usage

``` r
# S3 method for class 'SIS'
setup_skillset_XH(xds_obj, i)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

the **`xds`** object

## Note

This method dispatches on `class(xds_obj$XH_obj)`
