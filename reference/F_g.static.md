# Static model mosquito mortality rate (**MY**)

Return the baseline mosquito mortality rate for a static model.

## Usage

``` r
# S3 method for class 'static'
F_g(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\g\\, the baseline mosquito mortality rate
