# Apply effect sizes for `RMdts` (**MY**)

Leave the parameters unchanged; this module does not implement
effect-size modifications.

## Usage

``` r
# S3 method for class 'RMdts'
MEffectSizes(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
