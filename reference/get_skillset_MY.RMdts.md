# Get the skill set for `RMdts` (**MY**)

Return the capabilities and compatibilities of the `RMdts` module as a
list.

## Usage

``` r
# S3 method for class 'RMdts'
get_skillset_MY(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- s:

  the species index

## Value

the **MY** module skill set, as a list
