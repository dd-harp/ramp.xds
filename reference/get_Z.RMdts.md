# Get the initial infective mosquito density

Get the initial infective mosquito density

## Usage

``` r
# S3 method for class 'RMdts'
get_Z(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the initial infective mosquito population density
