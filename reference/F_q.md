# Compute the baseline human fraction (**MY**)

Compute the baseline human fraction, \\q\\.

## Usage

``` r
F_q(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nPatches`
