# Get the **XH** module skill set

Return a list of the **XH** module's capabilities.

## Usage

``` r
# S3 method for class 'SIS'
get_skillset_XH(xds_obj, i)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

the **XH** module skill set, as a list
