# XH modules

A List of Modules for the **XH**-Component

## In **`ramp.xds`**

- [`trivialXH`](https://dd-harp.github.io/ramp.xds/reference/trivialXH.md) -
  the trivial module

- [`SIS`](https://dd-harp.github.io/ramp.xds/reference/SIS.md) — *ode*
  or *dts* — a generalized *S-I-S* compartmental model

- [`hMoI`](https://dd-harp.github.io/ramp.xds/reference/hMoI.md) — *ode*
  — a hybrid model for infection and detection

## In **`ramp.library`**

- **Malaria**

  - `garki` - an implementation of the Garki Model for malaria

  - `SIP` - a compartmental model with treatment and chemoprotection

  - `SIPd` - a compartmental model with a fixed delay for
    chemoprotection

- **Compartmental Models**

  - `SIR` - an **SIR** compartmental model

  - `SIRS` - an **SIRS** compartmental model

  - `SEIR` - an **SEIR** compartmental model

  - `SEIRV` - an **SEIRV** compartmental model

  - `SEIS` - an **SEIS** compartmental model

  - `SEISd` - an **SEIS** compartmental model, as a delay differential
    equation
