# Set up mosquito mortality rate

Set up the mosquito mortality strategy and validate its rates.

## Usage

``` r
setup_g(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a mosquito mortality rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
