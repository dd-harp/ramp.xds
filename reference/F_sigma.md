# Compute the baseline patch emigration rate (**MY**)

Compute the baseline patch emigration rate, \\\sigma\\.

## Usage

``` r
F_sigma(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nPatches`
