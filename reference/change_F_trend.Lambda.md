# Change F_trend

Change the trend function when `forced_by = "Lambda"`

## Usage

``` r
# S3 method for class 'Lambda'
change_F_trend(F, xds_obj, ix = 1)
```

## Arguments

- F:

  new trend function

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an **`xds`** object
