# Constant baseline blood feeding rate (**MY**)

Return the baseline blood feeding rate for a static model.

## Usage

``` r
# S3 method for class 'static'
F_f(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\f\\, the baseline blood feeding rate
