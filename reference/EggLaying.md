# Compute eggs laid

Compute eggs laid at time \\t\\

## Usage

``` r
EggLaying(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
