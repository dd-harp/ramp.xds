# Change F_age

Change the relative biting rate function by age. The function `F` should
have the form \\F_a(a,V)\\. If the variable \\V\\ is not used, its
default value should be set to an empty list.

## Usage

``` r
change_F_age(F, xds_obj)
```

## Arguments

- F:

  new age function

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
