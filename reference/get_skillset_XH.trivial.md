# The **XH** module skill set

The **XH** skill set is a list of a module's capabilities

## Usage

``` r
# S3 method for class 'trivial'
get_skillset_XH(xds_obj, i)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- i:

  the species index

## Value

the **XH** module skill set, as a list
