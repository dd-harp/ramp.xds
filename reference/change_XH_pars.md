# Change **XH** parameters

Replace the parameters with new values named in the list `options`.

## Usage

``` r
change_XH_pars(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the vector species index

## Value

an **`xds`** object
