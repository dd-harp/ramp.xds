# Change functions (**L**)

A list of change functions for aquatic mosquito modules.

- [`change_L_inits`](https://dd-harp.github.io/ramp.xds/reference/change_L_inits.md)
  – change initial values

- [`change_L_pars`](https://dd-harp.github.io/ramp.xds/reference/change_L_pars.md)
  – change parameters

- [`change_psi`](https://dd-harp.github.io/ramp.xds/reference/change_psi.md)
  – change the maturation rate

- [`change_phi`](https://dd-harp.github.io/ramp.xds/reference/change_phi.md)
  – change the density-independent mortality rate

- [`change_xi`](https://dd-harp.github.io/ramp.xds/reference/change_xi.md)
  – change the delayed maturation parameter

- [`change_theta`](https://dd-harp.github.io/ramp.xds/reference/change_theta.md)
  – change the slope of density-dependent mortality
