# Plot the forcing pattern

Plot the composed time series function forcing a model

## Usage

``` r
show_forcing(xds_obj, tm = seq(0, 730, by = 5), add = FALSE)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- tm:

  the time points

- add:

  add to existing plot

## Value

the seasonal pattern, invisibly
