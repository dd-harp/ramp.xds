# Change mean forcing

Change mean infectious biting rate, \\fqZ\\

## Usage

``` r
# S3 method for class 'fqZ'
change_mean_forcing(X, xds_obj, ix = 1)
```

## Arguments

- X:

  the new mean forcing parameter

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an **`xds`** object
