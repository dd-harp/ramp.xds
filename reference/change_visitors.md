# Change the visitors

Update the visitors for the \\s^{th}\\ vector species.

## Usage

``` r
change_visitors(visitors, xds_obj, s = 1)
```

## Arguments

- visitors:

  the availability of visitors

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
