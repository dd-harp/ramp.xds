# Compute the baseline oviposition rate (**MY**)

Compute the baseline oviposition rate, \\\nu\\.

## Usage

``` r
F_nu(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nPatches`
