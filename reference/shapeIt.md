# Check the shape and dimensions of a model object

Check the shape and dimensions of a model object

## Usage

``` r
shapeIt(obj, d1, d2)
```

## Arguments

- obj:

  a [numeric](https://rdrr.io/r/base/numeric.html) input

- d1:

  the required number of rows

- d2:

  the required number of columns

## Value

[matrix](https://rdrr.io/r/base/matrix.html)
