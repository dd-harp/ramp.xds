# Set up ovitraps

Set up random values for ovitrap availability

## Usage

``` r
# S3 method for class 'random'
setup_ovitraps(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** object
