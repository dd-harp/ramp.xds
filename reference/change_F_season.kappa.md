# Change F_season

Change the season function when `forced_by = "kappa"`

## Usage

``` r
# S3 method for class 'kappa'
change_F_season(F, xds_obj, ix = 1)
```

## Arguments

- F:

  a seasonal pattern function

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an **`xds`** object
