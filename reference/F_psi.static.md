# Static model for the maturation rate (**L**)

Return the baseline maturation rate for a static model.

## Usage

``` r
# S3 method for class 'static'
F_psi(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\psi\\, the baseline maturation rate
