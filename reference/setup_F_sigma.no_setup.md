# Set up F_sigma (no setup) (**MY**)

Leave the existing patch emigration rate configuration unchanged.

## Usage

``` r
# S3 method for class 'no_setup'
setup_F_sigma(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a patch emigration rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
