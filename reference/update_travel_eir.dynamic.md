# Update travel_eir

Update travel_eir when it changes dynamically

## Usage

``` r
# S3 method for class 'dynamic'
update_travel_eir(t, y, xds_obj, i)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** object
