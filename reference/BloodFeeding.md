# Blood feeding

Compute and store host available, \\W_H\\, total blood host available,
\\B\\, the time spent matrix \\\Theta\\, and the time-at-risk matrix
\\\Psi\\,

## Usage

``` r
BloodFeeding(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
