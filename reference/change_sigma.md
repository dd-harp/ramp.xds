# Change the patch emigration rate

Update and validate the patch emigration rate for the \\s^{th}\\ vector
species, then update the demographic matrix.

## Usage

``` r
change_sigma(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
