# Change age

Change parameters for the relative biting rates by age and rebuild the
function

## Usage

``` r
change_age(X, xds_obj, ix = 1)
```

## Arguments

- X:

  a list with new parameters

- xds_obj:

  an **`xds`** model object

- ix:

  the vector species index

## Value

an **`xds`** object
