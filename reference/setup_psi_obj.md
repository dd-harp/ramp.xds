# Set up bionomic port for maturation rate (**L**)

Set up a [bionomic
port](https://dd-harp.github.io/ramp.xds/reference/xds_info_port.md) to
compute the baseline maturation rate, \\psi\\, for a static model.

## Usage

``` r
setup_psi_obj(psi, L_obj)
```

## Arguments

- psi:

  the maturation rate

- L_obj:

  an **`L`** module object

## Value

an **`L`** module object
