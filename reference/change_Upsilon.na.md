# Leave Upsilon unchanged (**MY**)

Return the model object without changing \\\Upsilon\\ when the
survival-and-dispersal matrix is not required.

## Usage

``` r
# S3 method for class 'na'
change_Upsilon(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

an **`xds`** model object
