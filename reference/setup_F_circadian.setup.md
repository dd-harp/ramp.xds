# Set the default circadian activity function

Set the activity function to
[F_one](https://dd-harp.github.io/ramp.xds/reference/F_one.md) for
vector species \\s\\.

## Usage

``` r
# S3 method for class 'setup'
setup_F_circadian(F_circadian, xds_obj, s = 1)
```

## Arguments

- F_circadian:

  a circadian function

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
