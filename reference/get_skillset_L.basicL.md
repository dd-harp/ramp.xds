# Get the skill set for `basicL` (**L**)

Return the capabilities and compatibilities of the `basicL` module as a
list.

## Usage

``` r
# S3 method for class 'basicL'
get_skillset_L(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- s:

  the species index

## Value

the **L** module skill set, as a list
