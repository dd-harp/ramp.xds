# Update the blood_search_weights

The `static` method returns `xds_obj` unmodified

## Usage

``` r
# S3 method for class 'static'
update_blood_search_weights(t, y, xds_obj, i)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

an **`xds`** object
