# Compute the baseline mosquito mortality rate (**MY**)

Compute the baseline mosquito mortality rate, \\g\\.

## Usage

``` r
F_g(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nPatches`
