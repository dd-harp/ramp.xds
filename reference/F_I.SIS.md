# Compute infectious density for `SIS`

In the `SIS` model family, infectious density is \\cI\\.

## Usage

``` r
# S3 method for class 'SIS'
F_I(t, y, xds_obj, i)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

Infectious density
