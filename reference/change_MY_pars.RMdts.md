# Change parameters for `RMdts` (**MY**)

Change static parameter values named in `options`, leaving other values
unchanged.

## Usage

``` r
# S3 method for class 'RMdts'
change_MY_pars(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** model object
