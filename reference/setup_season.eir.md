# Change season parameters

Change parameters for the seasonality function when `forced_by = "eir"`

## Usage

``` r
# S3 method for class 'eir'
setup_season(X, xds_obj, ix = 1)
```

## Arguments

- X:

  a seasonality function object

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an **`xds`** object
