# Get Variables

A generic function to retrieve variables from the **`xds`** model
object.

## Usage

``` r
get_variables(opts, t, y, xds_obj, ix)
```

## Arguments

- opts:

  an options list used for dispatch

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

a list of named variables
