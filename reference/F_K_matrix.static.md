# Dynamically update a K Matrix

Implements
[F_K_matrix](https://dd-harp.github.io/ramp.xds/reference/F_K_matrix.md)
for a static model

## Usage

``` r
# S3 method for class 'static'
F_K_matrix(t, xds_obj, s)
```

## Arguments

- t:

  current simulation time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

an **`xds`** object
