# ramp.demog

The package **`ramp.demog`** has functions and utilities to handle human
vital dynamics and aging. The package also handles ***principled
stratification*** to handle heterogeneity in epidemiologically relevant
traits.

**GitHub**

- [code repository](https://github.com/dd-harp/ramp.demog)

- [github.io](https://dd-harp.github.io/ramp.demog/)

To install the latest version from GitHub, run the following lines of
code in an R session.

\
[`library`](https://rdrr.io/r/base/library.html)`(`[`devtools`](https://devtools.r-lib.org/)`)`\
