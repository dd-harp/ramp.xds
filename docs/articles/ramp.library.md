# ramp.library

**`ramp.library`** includes new modules for three dynamical components:

- **X** component – modules describing the epidemiology of malaria and
  other mosquito-transmitted pathogens.

- **MY** component – modules describing adult mosquito ecology and
  infection dynamics

- **L** component – modules describing aquatic mosquito ecology

**GitHub**

- [code repository](https://github.com/dd-harp/ramp.library)

- [github.io](https://dd-harp.github.io/ramp.library/)

To install the latest version from GitHub, run the following lines of
code in an R session.

``` r

library(devtools)
devtools::install_github("dd-harp/ramp.library")
```
