# ramp.qa

The package **`ramp.qa`** has functions and utilities that take a
computational approach to qualitative analysis, including:

- Thresholds

- Scaling Relationships

- Connectivity

**GitHub**

- [code repository](https://github.com/dd-harp/ramp.qa)

- [github.io](https://dd-harp.github.io/ramp.qa/)

To install the latest version from GitHub, run the following lines of
code in an R session.

\
[`library`](https://rdrr.io/r/base/library.html)`(`[`devtools`](https://devtools.r-lib.org/)`)`\
`devtools``::`[`install_github`](https://devtools.r-lib.org/reference/install-deprecated.html)`(``"dd-harp/ramp.qa"``)`
