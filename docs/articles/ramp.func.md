# ramp.func

A function library, including:

- Utilities to build forcing functions

- Utilities to build kernels

**GitHub**

- [code repository](https://github.com/dd-harp/ramp.func)

- [github.io](https://dd-harp.github.io/ramp.func/)

To install the latest version from GitHub, run the following lines of
code in an R session.

``` r

library(devtools)
devtools::install_github("dd-harp/ramp.func")
```
