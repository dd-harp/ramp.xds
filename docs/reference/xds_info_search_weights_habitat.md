# Habitat Search Weights

Each aquatic habitat is assigned a search weight that contributes to its
availability to mosquitoes and the allocation of eggs among habitats.
See
[setup_habitat_search_weights](https://dd-harp.github.io/ramp.xds/reference/setup_habitat_search_weights.md)
for configuration.
