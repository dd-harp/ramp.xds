# Set up death rates

Set death rates to zero.

## Usage

``` r
# S3 method for class 'zero'
setup_deaths(name, xds_obj, options = list(), i = 1)
```

## Arguments

- name:

  a numeric vector, a setup function name, or an options list

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- i:

  the host species index

## Value

an **`xds`** model object
