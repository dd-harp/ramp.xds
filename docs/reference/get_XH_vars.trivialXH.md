# List variables for `trivialXH` (**XH**)

Return an empty list

## Usage

``` r
# S3 method for class 'trivialXH'
get_XH_vars(y, xds_obj, i)
```

## Arguments

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

a [list](https://rdrr.io/r/base/list.html)
