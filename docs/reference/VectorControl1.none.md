# Compute Vector Control Effect Sizes

Do no vector control: the **`xds`** object is returned unmodified.

## Usage

``` r
# S3 method for class 'none'
VectorControl1(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object

## Note

No control or `none` is the default setting
