# Compute blood feeding objects: static models

Return the blood feeding objects unmodified

## Usage

``` r
# S3 method for class 'static'
BloodFeeding(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
