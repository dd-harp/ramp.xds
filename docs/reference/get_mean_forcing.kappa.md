# Get mean forcing

Get net infectiousness.

## Usage

``` r
# S3 method for class 'kappa'
get_mean_forcing(xds_obj, ix = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

a [vector](https://rdrr.io/r/base/vector.html) of net infectiousness for
the indexed host species
