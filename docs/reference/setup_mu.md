# Set up emigration-loss fraction

Configure and validate the emigration-loss fraction.

## Usage

``` r
setup_mu(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an emigration-loss fraction or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
