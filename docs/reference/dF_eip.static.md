# Time derivative of the EIP for a static model (**MY**)

Return zero because the extrinsic incubation period is constant.

## Usage

``` r
# S3 method for class 'static'
dF_eip(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

zero
