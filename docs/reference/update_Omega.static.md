# Leave the static demographic matrix unchanged (**MY**)

Return the model object without changing the demographic matrix.

## Usage

``` r
# S3 method for class 'static'
update_Omega(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

an **`xds`** model object
