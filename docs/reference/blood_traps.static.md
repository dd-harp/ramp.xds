# Update static blood trap availability

The static method returns `xds_obj` unmodified.

## Usage

``` r
# S3 method for class 'static'
blood_traps(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
