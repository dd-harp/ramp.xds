# Compute beta

This function computes the mixing matrix, beta using search weights
adjusted for the fraction of time not traveling.

## Usage

``` r
compute_beta(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
