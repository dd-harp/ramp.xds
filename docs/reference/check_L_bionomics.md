# Check mosquito bionomics (**L**)

Currently returns `xds_obj` unchanged; no consistency checks are
performed.

## Usage

``` r
check_L_bionomics(xds_obj, t = 0, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- t:

  a vector of times

- s:

  the vector species index

## Value

an **`xds`** model object
