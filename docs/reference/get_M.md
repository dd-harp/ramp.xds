# Get the initial mosquito population density

Get the initial mosquito population density

## Usage

``` r
get_M(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the initial density as a [numeric](https://rdrr.io/r/base/numeric.html)
vector
