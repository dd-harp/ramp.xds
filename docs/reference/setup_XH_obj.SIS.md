# Set up `SIS` (**XH**)

Set up an `SIS` model object for the **XH** component

## Usage

``` r
# S3 method for class 'SIS'
setup_XH_obj(XHname, residence, xds_obj, options = list(), i = 1)
```

## Arguments

- XHname:

  the model name

- residence:

  the residence vector

- xds_obj:

  an **`xds`** model object

- options:

  model options as a named list

- i:

  the host species index

## Value

an **`xds`** object
