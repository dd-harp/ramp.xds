# Set up variable indices for `trivialMY` (**MY**)

The module has no state variables; return the model object unchanged.

## Usage

``` r
# S3 method for class 'trivialMY'
setup_MY_ix(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
