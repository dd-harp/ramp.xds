# Check other blood hosts

Check that

- all elements are non-negative

- length(bad_habitats) == nPatches

## Usage

``` r
check_bad_habitats(bad_habitats, nP)
```

## Arguments

- bad_habitats:

  bad habitat availability

- nP:

  the number of patches
