# Update the travel eir

Port function for the travel eir , \\\Theta\\. Dispatches on
`class(xds_obj$XY_interface$travel_eir_obj[[i]])`.

## Usage

``` r
update_travel_eir(t, y, xds_obj, i)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** object
