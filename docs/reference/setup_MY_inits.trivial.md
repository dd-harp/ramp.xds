# Setup initial values for `trivial` (**MY**)

Return the **`xds`** object unmodified

## Usage

``` r
# S3 method for class 'trivial'
setup_MY_inits(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a [list](https://rdrr.io/r/base/list.html)

- s:

  the vector species index

## Value

an **`xds`** object
