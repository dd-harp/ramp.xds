# Update visitors

Port function to compute the availability of visitors.

## Usage

``` r
update_visitors(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
