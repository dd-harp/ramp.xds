# Habitat Dynamics

Update habitat search weights, unsuitable habitats, and ovitraps, and
update resource availability for egg laying.

## Usage

``` r
habitat_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
