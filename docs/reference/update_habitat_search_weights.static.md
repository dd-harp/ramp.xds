# Update the habitat_search_weights

The `static` method returns `xds_obj` unmodified

## Usage

``` r
# S3 method for class 'static'
update_habitat_search_weights(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** object
