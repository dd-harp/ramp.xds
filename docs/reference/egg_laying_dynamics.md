# Egg laying dynamics

Update the laying matrix and compute eggs laid.

## Usage

``` r
egg_laying_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
