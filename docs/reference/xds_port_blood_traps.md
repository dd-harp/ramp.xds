# Blood Traps

Availability of traps that attract blood-seeking mosquitoes.

## Blood Traps

The blood-feeding interface has a port for blood trap availability. It
contributes to total availability \\(B\\) and is initialized to zero in
each patch. Values are configured for each vector species through
[setup_blood_traps](https://dd-harp.github.io/ramp.xds/reference/setup_blood_traps.md).
