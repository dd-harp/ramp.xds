# Get the habitat membership vector

Inspect the habitat membership vector.

## Usage

``` r
get_habitats(xds_obj)
```

## Arguments

- xds_obj:

  an **`xds`** model object

## Value

the patch membership for aquatic habitats, a numeric vector
