# Set up type 2 oviposition rates (**MY**)

Configure a type 2 functional response for the oviposition rate.

## Usage

``` r
# S3 method for class 'type2'
setup_F_nu(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an oviposition rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
