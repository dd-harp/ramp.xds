# Compute the EIP derivative (**MY**)

Compute the time derivative of the extrinsic incubation period.

## Usage

``` r
dF_eip(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

the time derivative of the extrinsic incubation period; zero for a
static model
