# Mosquito bionomics (**L**)

Compute baseline bionomic parameter values for an **L** component
module.

## Usage

``` r
LBionomics(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** model object
