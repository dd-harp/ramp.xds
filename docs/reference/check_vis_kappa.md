# Check vis_kappa

Check that

- all elements are non-negative

- length(vis_kappa) = nPatches

## Usage

``` r
check_vis_kappa(vis_kappa, nP)
```

## Arguments

- vis_kappa:

  net infectiousness of the visitor population

- nP:

  the number of patches
