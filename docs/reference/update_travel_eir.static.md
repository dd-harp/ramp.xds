# Update travel_eir

Return `xds_obj` unchanged for a static travel EIR port.

## Usage

``` r
# S3 method for class 'static'
update_travel_eir(t, y, xds_obj, i)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** model object
