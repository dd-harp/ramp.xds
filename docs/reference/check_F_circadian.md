# Check circadian

Check that

- all elements are non-negative

- length(circadian) == nPatc

## Usage

``` r
check_F_circadian(F_circadian, tol = 1e-05)
```

## Arguments

- F_circadian:

  a circadian pattern function

- tol:

  a tolerance function
