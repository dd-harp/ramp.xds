# Set new V initial values

This method dispatches on the type of `xds_obj$V_obj[[i]]`.

## Usage

``` r
change_V_inits(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the auxiliary-variable module index

## Value

an **`xds`** model object
