# Set up random travel EIR

Set up random values for travel EIR.

## Usage

``` r
# S3 method for class 'random'
setup_travel_eir(name, xds_obj, options = list(), i = 1)
```

## Arguments

- name:

  a setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- i:

  the host species index

## Value

an **`xds`** model object
