# Compute transmission, the dynamic case

Compute transmission terms with a dynamic mixing matrix

## Usage

``` r
# S3 method for class 'dynamic'
Transmission(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
