# Set up bionomic port for density-independent mortality rate (**L**)

Set up a [bionomic
port](https://dd-harp.github.io/ramp.xds/reference/xds_info_port.md) to
compute the baseline density-independent mortality rate, \\(phi\\), for
a static model.

## Usage

``` r
setup_phi_obj(phi, L_obj)
```

## Arguments

- phi:

  the density-independent mortality rate

- L_obj:

  an **`L`** module object

## Value

an **`L`** module object
