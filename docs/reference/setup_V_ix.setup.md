# Add indices for auxiliary variables

Assign indices to the auxiliary variables following the existing model
indices.

## Usage

``` r
# S3 method for class 'setup'
setup_V_ix(xds_obj, i)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- i:

  the variable index

## Value

an **`xds`** model object

## Note

Index the variables.
