# Apply effect sizes for `basicL` (**L**)

Apply effect sizes to the baseline bionomic parameter values for the
`basicL` module.

## Usage

``` r
# S3 method for class 'basicL'
LEffectSizes(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** model object
