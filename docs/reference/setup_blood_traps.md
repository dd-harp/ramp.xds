# Set up a blood_traps

Set up a blood_traps

## Usage

``` r
setup_blood_traps(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a or setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the host species index

## Value

an **`xds`** object
