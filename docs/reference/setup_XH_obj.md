# Set up **XH** model object

Set the parameter values and configure a model for the **X** Component

## Usage

``` r
setup_XH_obj(Xname, residence, HPop, xds_obj, i, options = list())
```

## Arguments

- Xname:

  the model name

- residence:

  the residence vector

- HPop:

  the initial human population size

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

- options:

  model options as a named list

## Value

an **`xds`** object
