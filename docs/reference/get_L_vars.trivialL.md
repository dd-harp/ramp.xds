# List variables for `trivialL` (**L**)

Returns an empty list; the `trivialL` module has no state variables

## Usage

``` r
# S3 method for class 'trivialL'
get_L_vars(y, xds_obj, s)
```

## Arguments

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an empty [list](https://rdrr.io/r/base/list.html)
