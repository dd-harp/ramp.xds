# Setup initial values (**XH**)

This method dispatches on `xds_obj$XH_obj[[i]]`.

## Usage

``` r
setup_XH_inits(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a [list](https://rdrr.io/r/base/list.html)

- i:

  the host species index

## Value

an **`xds`** object
