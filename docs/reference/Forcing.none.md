# Forcing

Implements no `Forcing`, the default.

## Usage

``` r
# S3 method for class 'none'
Forcing(t, xds_obj)
```

## Arguments

- t:

  current simulation time

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

## Note

Dynamic forcing is implemented in **`ramp.forcing`**
