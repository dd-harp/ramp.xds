# Check time away

Check that

- the input is numeric

- all elements are non-negative

- all elements are at most 1

- the length is `Nh`

## Usage

``` r
check_time_away(TA, Nh)
```

## Arguments

- TA:

  a time away vector

- Nh:

  the number of population strata
