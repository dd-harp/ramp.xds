# Other blood hosts

The `S3` definition for the function that computes other_blood_hosts

## Usage

``` r
other_blood_hosts(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
