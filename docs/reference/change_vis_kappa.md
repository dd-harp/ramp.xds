# Change the vis_kappa

Update the vis_kappa for the \\s^{th}\\ vector species, and trigger
updates for the `XY` interface.

## Usage

``` r
change_vis_kappa(vis_kappa, xds_obj, s = 1)
```

## Arguments

- vis_kappa:

  a vis_kappa

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
