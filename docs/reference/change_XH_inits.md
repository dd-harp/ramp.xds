# Change initial values (**XH**)

Change the stored initial values for any variables named in `options`
leaving other values unchanged.

## Usage

``` r
change_XH_inits(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the vector species index

## Value

an **`xds`** object
