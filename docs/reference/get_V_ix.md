# Get indices for auxiliary variables

Retrieve the values of the indices for the variables.

## Usage

``` r
get_V_ix(xds_obj, i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- i:

  the auxiliary-variable module index

## Value

the index [vector](https://rdrr.io/r/base/vector.html)
