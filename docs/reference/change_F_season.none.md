# Change F_season

Change the seasonality function when `forced_by = "none"`

## Usage

``` r
# S3 method for class 'none'
change_F_season(F, xds_obj, s = 1)
```

## Arguments

- F:

  a seasonal pattern function

- xds_obj:

  an **`xds`** model object

- s:

  the vector species indeF

## Value

an **`xds`** object
