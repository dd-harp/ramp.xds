# Change parameters (**L**)

For the **L** module for the \\(s^{th}\\) species, change parameter
values named in `options`, leaving other values unchanged.

## Usage

``` r
change_L_pars(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** object
