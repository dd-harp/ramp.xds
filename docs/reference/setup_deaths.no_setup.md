# Set up death rates

Change nothing

## Usage

``` r
# S3 method for class 'no_setup'
setup_deaths(name, xds_obj, options = list(), i = 1)
```

## Arguments

- name:

  a or setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- i:

  the host species index

## Value

an **`xds`** object
