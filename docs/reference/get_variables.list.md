# Get Variables

The NULL case for
[get_variables](https://dd-harp.github.io/ramp.xds/reference/get_variables.md)

## Usage

``` r
# S3 method for class 'list'
get_variables(opts, t, y, xds_obj, ix)
```

## Arguments

- opts:

  an options list and dispatching

- t:

  current simulation time

- y:

  state vector

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an empty list
