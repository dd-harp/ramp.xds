# Compute time spent

Return the time spent objects unmodified

## Usage

``` r
# S3 method for class 'static'
timespent(t, y, xds_obj, i)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** model object
