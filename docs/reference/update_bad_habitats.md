# Update other blood hosts

Port function for the bad_habitats, \\\Theta\\. Dispatches on
`class(xds_obj$patches$bad_habitats_obj[[s]])`.

## Usage

``` r
update_bad_habitats(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
