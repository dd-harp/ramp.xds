# Get the Mosquito Dispersal Matrix

Get the Mosquito Dispersal Matrix

## Usage

``` r
# S3 method for class 'K'
get_K_matrix(xds_obj, which_K = "K", s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- which_K:

  which K_matrix

- s:

  the vector species index

## Value

an **`xds`** object
