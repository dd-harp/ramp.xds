# Compute survival and dispersal through the EIP for xde (**MY**)

Compute survival and dispersal through the EIP for xde (**MY**)

## Usage

``` r
F_Upsilon_xde(eip, Omega)
```

## Arguments

- eip:

  the extrinsic incubation period

- Omega:

  the demographic matrix

## Value

a [matrix](https://rdrr.io/r/base/matrix.html) of dimensions `nPatches`
by `nPatches`
