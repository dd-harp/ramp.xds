# Get the slope of density-dependent mortality for `basicL` (**L**)

Get the slope of density-dependent mortality for `basicL` (**L**)

## Usage

``` r
# S3 method for class 'basicL'
get_theta(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the slope of density-dependent mortality
