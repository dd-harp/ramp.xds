# Check mosquito mortality rate

Check that the mosquito mortality rates are non-negative and have length
`nPatches`.

## Usage

``` r
check_g(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the validated mosquito mortality rate
