# Change the travel eir

Update the travel eir for the \\i^{th}\\ host species

## Usage

``` r
change_travel_eir(travel_eir, xds_obj, i = 1)
```

## Arguments

- travel_eir:

  a travel eir vector

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

an **`xds`** object
