# Set up a **V** module

Set the parameter values and configure a model for the **V** component.

## Usage

``` r
setup_V_obj(XHname, xds_obj, options = list(), i = 1)
```

## Arguments

- XHname:

  the model name

- xds_obj:

  an **`xds`** model object

- options:

  model options as a named list

- i:

  the auxiliary-variable module index

## Value

an **`xds`** model object
