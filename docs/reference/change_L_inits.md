# Change initial values (**L**)

Change the stored initial values for any variables named in `options`,
leaving other values unchanged.

## Usage

``` r
change_L_inits(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** object
