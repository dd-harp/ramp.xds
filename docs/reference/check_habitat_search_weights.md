# Check habitat search weights

Check that

- all elements are non-negative

- length(habitat_search_weights) == nHabitats

## Usage

``` r
check_habitat_search_weights(search_weights, nQ)
```

## Arguments

- search_weights:

  habitat search weights

- nQ:

  the number of habitats
