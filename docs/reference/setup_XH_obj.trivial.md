# Set up `trivial` (**XH**)

Implements
[setup_XH_obj](https://dd-harp.github.io/ramp.xds/reference/setup_XH_obj.md)
for the trivial model

## Usage

``` r
# S3 method for class 'trivial'
setup_XH_obj(XHname, residence, xds_obj, options = list(), i = 1)
```

## Arguments

- XHname:

  the model name

- residence:

  the residence vector

- xds_obj:

  an **`xds`** model object

- options:

  model options as a named list

- i:

  the host species index

## Value

an **`xds`** object
