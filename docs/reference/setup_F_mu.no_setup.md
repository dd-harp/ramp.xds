# Set up F_mu (no setup) (**MY**)

Leave the existing emigration-loss fraction configuration unchanged.

## Usage

``` r
# S3 method for class 'no_setup'
setup_F_mu(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an emigration-loss fraction or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
