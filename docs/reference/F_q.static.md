# Static model human fraction (**MY**)

Return the baseline human fraction for a static model.

## Usage

``` r
# S3 method for class 'static'
F_q(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\(q\\), the baseline human fraction
