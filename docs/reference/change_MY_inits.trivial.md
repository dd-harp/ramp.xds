# Change initial values for `trivial` (**MY**)

For the `trivial` module (**MY**) for the \\(s^{th}\\) species, change
initial values named in `options` leaving other values unchanged.

## Usage

``` r
# S3 method for class 'trivial'
change_MY_inits(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** object
