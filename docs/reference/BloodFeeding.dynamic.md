# Compute blood feeding objects dynamically

Update time-at-risk matrices and compute local and total blood host
availability.

## Usage

``` r
# S3 method for class 'dynamic'
BloodFeeding(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
