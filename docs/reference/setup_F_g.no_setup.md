# Set up F_g (no setup) (**MY**)

Leave the existing mosquito mortality rate configuration unchanged.

## Usage

``` r
# S3 method for class 'no_setup'
setup_F_g(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a mosquito mortality rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
