# Set up random EIP values (**MY**)

Configure random extrinsic incubation periods using
[make_F_eip_random](https://dd-harp.github.io/ramp.xds/reference/make_F_eip_random.md).

## Usage

``` r
# S3 method for class 'random'
setup_F_eip(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an EIP value or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
