# Update availability of egg-laying habitats

Set the values of \\(Q\\) and \\(Q\_{all}\\), which describe the
availability of any habitat or device that would attract mosquitoes and
induce them to lay eggs.

## Usage

``` r
update_all_available_water(xds_obj)
```

## Arguments

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
