# Update the blood_traps

The `static` method returns `xds_obj` unmodified

## Usage

``` r
# S3 method for class 'static'
update_blood_traps(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
