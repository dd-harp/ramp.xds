# Change the time spent

Update the time spent for the \\i^{th}\\ host species, and trigger
updates for the `XY` interface.

## Usage

``` r
change_time_away(time_away, xds_obj, i = 1)
```

## Arguments

- time_away:

  a time spent vector

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

an **`xds`** object
