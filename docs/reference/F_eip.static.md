# Static model for the EIP (**MY**)

Return the extrinsic incubation period for a static model.

## Usage

``` r
# S3 method for class 'static'
F_eip(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

\\(eip\\), the extrinsic incubation period in days
