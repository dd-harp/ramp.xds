# Set up seasonal forcing

Set up season for the no-forcing case.

## Usage

``` r
# S3 method for class 'none'
setup_season(X, xds_obj, ix = 1)
```

## Arguments

- X:

  a seasonality function object

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

an **`xds`** model object
