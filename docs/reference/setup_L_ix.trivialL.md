# Set up indices for `trivialL` (**L**)

Return the **`xds`** object unmodified

``` r
# S3 method for class 'trivialL'
setup_L_ix(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** model object
