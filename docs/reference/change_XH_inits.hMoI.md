# Change initial values for `hMoI` (**XH**)

This method dispatches on the type of `xds_obj$XH_obj[[i]]`.

## Usage

``` r
# S3 method for class 'hMoI'
change_XH_inits(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the vector species index

## Value

an **`xds`** object
