# Importation Junction

Dispatches on `class(xds_obj$import_obj)` to update importation-related
parameters: time at home, travel EIR, visitor availability, and visitor
infectiousness.

## Usage

``` r
Importation(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
