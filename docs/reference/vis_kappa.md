# Compute NI of visitors

The `S3` definition for the function that computes vis_kappa

## Usage

``` r
vis_kappa(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
