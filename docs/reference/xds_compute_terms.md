# Compute exogenous variables and dynamical terms

Compute exogenous variables and dynamical terms

## Usage

``` r
xds_compute_terms(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
