# Make a WVB human feeding fraction configuration

Create a configuration object for the WVB human feeding fraction method.

## Usage

``` r
make_F_q_WVB(nPatches, options = list())
```

## Arguments

- nPatches:

  is the number of patches

- options:

  is a set of options that overwrites the defaults

## Value

a configuration object for
[F_q.WVB](https://dd-harp.github.io/ramp.xds/reference/F_q.WVB.md)
