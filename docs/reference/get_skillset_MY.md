# Get the skill set (**MY**)

Return the capabilities and compatibilities of an **MY** module.

## Usage

``` r
get_skillset_MY(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- s:

  the species index

## Value

the **MY** module skill set, as a list
