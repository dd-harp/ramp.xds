# Change initial values (**MY**)

Change initial values for the selected **MY** module using the values
supplied in `options`.

## Usage

``` r
change_MY_inits(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** model object
