# Set up default blood search weights

Initialize unit blood search weights for host species `i`.

## Usage

``` r
# S3 method for class 'setup'
setup_blood_search_weights(name, xds_obj, options = list(), i = 1)
```

## Arguments

- name:

  a setup method name or a numeric vector of weights

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- i:

  the host species index

## Value

an **`xds`** model object
