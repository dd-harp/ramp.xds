# Set up F_sigma

Set up a type 2 functional response to model the patch emigration rate

## Usage

``` r
# S3 method for class 'type2'
setup_F_sigma(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a or setup function name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** object
