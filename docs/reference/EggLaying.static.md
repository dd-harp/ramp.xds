# Compute eggs laid in aquatic habitats

Compute egg laying when the laying matrix doesn't change.

## Usage

``` r
# S3 method for class 'static'
EggLaying(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
