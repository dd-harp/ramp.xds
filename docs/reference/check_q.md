# Check human feeding fraction

Check that the human feeding fractions are between zero and one and have
length `nPatches`.

## Usage

``` r
check_q(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the validated human feeding fraction
