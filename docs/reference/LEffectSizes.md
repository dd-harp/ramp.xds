# Apply effect sizes (**L**)

Apply vector control effect sizes to baseline aquatic mosquito bionomic
parameter values.

## Usage

``` r
LEffectSizes(t, y, xds_obj, s)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** model object
