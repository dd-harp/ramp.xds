# Update time away

Port function for time away. Dispatches on
`class(xds_obj$XH_obj[[i]]$time_away_obj)`.

## Usage

``` r
update_time_away(t, y, xds_obj, i)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** model object
