# Setup a circadian pattern function

Update the circadian for the \\s^{th}\\ host species

## Usage

``` r
setup_F_circadian(F_circadian, xds_obj, s = 1)
```

## Arguments

- F_circadian:

  a circadian function or a method name (*e.g.* "setup")

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
