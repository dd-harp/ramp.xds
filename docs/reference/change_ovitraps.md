# Change ovitrap availability

Update the ovitraps for the \\s^{th}\\ vector species

## Usage

``` r
change_ovitraps(ovitraps, xds_obj, s = 1)
```

## Arguments

- ovitraps:

  ovitrap availability

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
