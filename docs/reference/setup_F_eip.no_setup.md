# Set up no F_eip

Leave the existing EIP configuration unchanged.

## Usage

``` r
# S3 method for class 'no_setup'
setup_F_eip(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  an EIP value or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
