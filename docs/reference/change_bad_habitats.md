# Change the bad_habitats

Update the bad habitats for the \\s^{th}\\ vector species, and trigger
updates for the `ML` interface.

## Usage

``` r
change_bad_habitats(bad_habitats, xds_obj, s = 1)
```

## Arguments

- bad_habitats:

  bad habitat availability

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
