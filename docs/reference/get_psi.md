# Get the maturation rate (**L**)

Get the maturation rate (**L**)

## Usage

``` r
get_psi(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the maturation rate(s)
