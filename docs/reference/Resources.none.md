# Resources (none)

The default no-op for Resources. All resource parameters retain their
configured values without modification.

## Usage

``` r
# S3 method for class 'none'
Resources(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
