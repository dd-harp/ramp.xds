# Compute Derivatives

Compute derivatives for a *human* model.

## Usage

``` r
# S3 method for class 'human'
xde_derivatives(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

a [list](https://rdrr.io/r/base/list.html) containing the vector of all
state derivatives
