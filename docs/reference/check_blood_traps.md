# Check other blood hosts

Check that

- all elements are non-negative

- length(blood_traps) == nPatc

## Usage

``` r
check_blood_traps(blood_traps, nP)
```

## Arguments

- blood_traps:

  traps availability

- nP:

  the number of patches
