# Check Time Spent Matrix

Check that

- there ar \\N_p\\ columns and \\N_h\\ rows

- the column sums are at most 1\`

## Usage

``` r
check_timespent_matrix(TS, Np, Nh)
```

## Arguments

- TS:

  a time spent matrix

- Np:

  the number of patches

- Nh:

  the number of population strata
