# Set up variable indices (**L**)

Set up variable indices for the selected **L** module.

## Usage

``` r
setup_L_ix(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the species index

## Value

an **`xds`** model object
