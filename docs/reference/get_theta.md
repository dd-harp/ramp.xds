# Get the slope of density-dependent mortality (**L**)

Get the slope of density-dependent mortality (**L**)

## Usage

``` r
get_theta(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the slope(s) of density-dependent mortality
