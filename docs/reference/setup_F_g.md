# Configure the mosquito mortality rate function (**MY**)

Configure the function used to compute the baseline mosquito mortality
rate.

## Usage

``` r
setup_F_g(name, xds_obj, options = list(), s = 1)
```

## Arguments

- name:

  a mosquito mortality rate or setup method name

- xds_obj:

  an **`xds`** model object

- options:

  configuration options

- s:

  the vector species index

## Value

an **`xds`** model object
