# Change the delayed maturation parameter (**L**)

Change the delayed maturation parameter for `basicL` for a static model

## Usage

``` r
change_xi(xi, xds_obj, s)
```

## Arguments

- xi:

  the delayed maturation parameter

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** model object
