# Aquatic Habitat Dynamics

Updates habitat availability with exogenous forcing on a parameter
affecting habitat availability.

## Usage

``` r
# S3 method for class 'dynamic'
AquaticHabitats(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
