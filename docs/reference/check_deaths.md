# Check deaths

Check that

- the death rate is numeric

- the death rate is not negative

- the death rates length is the number of strata

## Usage

``` r
check_deaths(death_rates, Nh)
```

## Arguments

- death_rates:

  death rates

- Nh:

  the number of population strata
