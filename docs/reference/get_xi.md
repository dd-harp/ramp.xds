# Get the delayed maturation parameter (**L**)

Get the delayed maturation parameter (**L**)

## Usage

``` r
get_xi(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the delayed maturation parameter(s)
