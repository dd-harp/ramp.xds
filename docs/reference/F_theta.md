# Compute the baseline slope of density-dependent mortality (**L**)

Compute the baseline slope of density-dependent mortality.

## Usage

``` r
F_theta(t, xds_obj, s)
```

## Arguments

- t:

  time

- xds_obj:

  an **`xds`** model object

- s:

  vector species index

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length
`nHabitats`
