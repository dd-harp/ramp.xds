# Change F_trend

Change the trend function when `forced_by = "Lambda"`

## Usage

``` r
# S3 method for class 'Lambda'
change_F_trend(F, xds_obj, s = 1)
```

## Arguments

- F:

  new trend function

- xds_obj:

  an **`xds`** model object

- s:

  the vector species indeF

## Value

an **`xds`** object
