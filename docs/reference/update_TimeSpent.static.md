# Update timespent

A utility to ensure that the timespent is updated properly after a
change

## Usage

``` r
# S3 method for class 'static'
update_timespent(t, y, xds_obj, i)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** object
