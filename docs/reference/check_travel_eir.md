# Check the travel eir

Check that

- the input is numeric

- the travel eir has length `Nh`

- all elements are non-negative

## Usage

``` r
check_travel_eir(teir, Nh)
```

## Arguments

- teir:

  a travel eir vector

- Nh:

  the number of population strata
