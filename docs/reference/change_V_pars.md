# Set new X parameter values

This method dispatches on the type of `xds_obj$V_obj[[s]]`.

## Usage

``` r
change_V_pars(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the vector species index

## Value

an **`xds`** object
