# The skill set

The skill set

## Usage

``` r
# S3 method for class 'trivialMY'
get_skillset_MY(xds_obj, s)

# S3 method for class 'trivial'
get_skillset_MY(xds_obj, s)
```

## Arguments

- xds_obj:

  an **`xds`** model object (or the module name)

- s:

  the species index

## Value

the **MY** module skill set, as a list

## Note

The compatibility name `"trivial"` returns the same skill set as
`"trivialMY"`.
