# blood_search_weights

The `S3` definition for the function that computes blood_search_weights

## Usage

``` r
blood_search_weights(t, y, xds_obj, i, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

- s:

  the vector species index

## Value

an **`xds`** object
