# Get parameters for `RMdts` (**MY**)

Get the stored parameter values for the `RMdts` model.

## Usage

``` r
# S3 method for class 'RMdts'
get_MY_pars(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

a [list](https://rdrr.io/r/base/list.html)
