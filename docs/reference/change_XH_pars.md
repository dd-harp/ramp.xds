# Change **XH** parameters

For the **XH** module for the \\(i^{th}\\) species, change parameter
values named in `options` leaving other values unchanged.

## Usage

``` r
change_XH_pars(xds_obj, options = list(), i = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- i:

  the vector species index

## Value

an **`xds`** object
