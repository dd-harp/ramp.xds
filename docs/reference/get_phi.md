# Get the density-independent mortality rate (**L**)

Get the density-independent mortality rate (**L**)

## Usage

``` r
get_phi(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

the density-independent mortality rate(s)
