# Change the birth rates

Modify the birth rates for a model with static population rates.

## Usage

``` r
change_births(birth_rates, xds_obj, i = 1)
```

## Arguments

- birth_rates:

  birth rates

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

## Value

an **`xds`** object
