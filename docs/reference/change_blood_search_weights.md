# Change the blood search weights

Change the *static* blood search weights

## Usage

``` r
change_blood_search_weights(blood_search_weights, xds_obj, i = 1)
```

## Arguments

- blood_search_weights:

  a blood_search_weights

- xds_obj:

  an **`xds`** model object

- i:

  the species index

## Value

an **`xds`** object
