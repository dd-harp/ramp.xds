# Get parameters (**L**)

Inspect the parameter values for the **L** module for the \\(s^{th}\\)
species

## Usage

``` r
get_L_pars(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

a [list](https://rdrr.io/r/base/list.html)
