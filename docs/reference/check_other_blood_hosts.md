# Check other blood host availability

Check that

- all elements are non-negative

- length(other_blood_hosts) == nP

## Usage

``` r
check_other_blood_hosts(other_blood_hosts, nP)
```

## Arguments

- other_blood_hosts:

  availability of other blood hosts

- nP:

  the number of patches
