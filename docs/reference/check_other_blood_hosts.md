# Check other blood hosts

Check that

- all elements are non-negative

- length(other_blood_hosts) == nPatc

## Usage

``` r
check_other_blood_hosts(other_blood_hosts, nP)
```

## Arguments

- other_blood_hosts:

  availbility of other blood hosts

- nP:

  the number of patches
