# Change mosquito mortality rate

Update the mosquito mortality rate for the \\s^{th}\\ vector species and
refresh the demographic matrix.

## Usage

``` r
change_g(xds_obj, s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
