# Set up bionomic port for human fraction (**MY**)

Set up a [bionomic
port](https://dd-harp.github.io/ramp.xds/reference/xds_info_port.md) to
compute the baseline human fraction, \\(q\\), for a static model.

## Usage

``` r
setup_q_obj(q, MY_obj)
```

## Arguments

- q:

  the human fraction

- MY_obj:

  an **`MY`** module object

## Value

an **`MY`** module object
