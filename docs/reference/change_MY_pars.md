# Change parameters (**MY**)

For the **MY** module for the \\(s^{th}\\) species, change parameter
values named in `options`, leaving other values unchanged.

## Usage

``` r
change_MY_pars(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** object
