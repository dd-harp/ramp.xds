# habitat_search_weights

The `S3` definition for the function that computes
habitat_search_weights

## Usage

``` r
habitat_search_weights(t, y, xds_obj, s)
```

## Arguments

- t:

  the time

- y:

  the state variables

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

## Value

an **`xds`** object
