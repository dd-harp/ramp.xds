# Change parameters for `basicL` (**L**)

Set the values of **L** component parameters

- `psi` or \\(\psi\\)

- `xi` or \\(\xi\\)

- `phi` or \\(\phi\\)

- `theta` or \\(\theta\\)

## Usage

``` r
# S3 method for class 'basicL'
change_L_pars(xds_obj, options = list(), s = 1)
```

## Arguments

- xds_obj:

  an **`xds`** model object

- options:

  a named list

- s:

  the vector species index

## Value

an **`xds`** object
