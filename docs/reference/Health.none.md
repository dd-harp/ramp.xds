# Set no exogenous health variables

After none setup, no exogenous variables are configured so `Health`
returns the **`ramp.xds`** model object without modification.

## Usage

``` r
# S3 method for class 'none'
Health(t, y, xds_obj)
```

## Arguments

- t:

  time

- y:

  dependent variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** model object
